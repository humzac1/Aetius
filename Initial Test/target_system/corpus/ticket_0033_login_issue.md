# TCK-0033: Repeated login failures after MFA setup

**Status:** Resolved · **Priority:** Medium

## Details

Customer set up MFA and then couldn't log in — time skew on their
authenticator app was the cause. Walked them through re-syncing the app's
clock. Confirmed working. Noted for the FAQ: MFA time-skew is a recurring
theme, maybe 3rd ticket this quarter on it.
